Privacy Policy

Last updated: November 11, 2026

Channel Stats Reader is a personal tool used only by its owner to read statistics of the owner's own YouTube channels.

Data accessed

With the owner's permission, the tool reads YouTube channel information and YouTube Analytics reports (for example views, watch time, audience retention and traffic sources) through Google's APIs. Access is read-only.

How the data is used

The data is used only to produce performance reports for the channel owner.

Storage and sharing

The data and the authorization token are stored on the owner's own computer. They are not sold, not used for advertising, and not shared with third parties.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer removes the stored authorization.

Contact

Questions can be sent to the developer contact email shown on the Google consent screen.
